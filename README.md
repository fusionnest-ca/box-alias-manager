# Box Alias Manager

Shortcuts to Box Drive folders that survive Box sync and work for every colleague — unlike native macOS aliases, which Box Drive corrupts.

## Install (macOS 10.13 or newer, Intel and Apple Silicon)

1. Download **[Box-Alias-Manager.dmg](https://github.com/fusionnest-ca/box-alias-manager/releases/latest/download/Box-Alias-Manager.dmg)**
2. Open it and drag **Box Alias Manager** to **Applications**

The app is signed and notarized by Apple, so it opens with a normal double-click.

## Use

- **Make a shortcut:** drag a Box Drive folder onto Box Alias Manager. A `FolderName.boxalias` appears next to the folder and is copied to your clipboard, so you can ⌘V it onto your Desktop, into another Box folder, anywhere.
- **Open a shortcut:** double-click the `.boxalias`. The folder opens in Finder from *your* Box Drive, whatever your username.

Requirements: Box Drive running, access to the folder in Box, and Box Alias Manager installed on the Mac that opens the shortcut.

## Update

Download the DMG again from the link above and replace the app in Applications.
